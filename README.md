# 따숨교육 랜딩 페이지 — 「당신의 교실로 갑니다」

Parallax 랜딩톤(제1회) 출품작의 공개 배포본입니다. https://song0328.github.io/ddasum-landing/

- 이 저장소는 GitHub Pages 배포용입니다. `index.html` 한 장과 공유 이미지 `og-finale.jpg`만 둡니다.
- 원본과 작업 기록은 비공개 저장소 `song0328/hackathon`의 `hackathons/parallax-landingthon-2026/`에 있습니다. 원본(`최종안/index.html`)을 고친 뒤 이 저장소로 복사해 push합니다.
- 11/28 공식 기준 검수 뒤 현재판 제출을 권장했습니다. 최신 첨부 스크린샷·제출 문구는 원본 저장소에 준비했으며 실제 출품은 아직 하지 않았습니다. 자세한 건 원본 폴더의 `생각노트.md`.

11/28: 첫 장면 바닥·흐린 반사·접촉 그림자, 교실 마루/책상 재질과 조명을 조정했습니다. 표면 지도는 HTML 안에 포함됩니다. 이후 피드백에 따라 끝 장면 상자를 PC 240·폰 48개로 더 줄이고 중앙 집중을 풀어 여백을 확보했습니다. 첫 장면 기본 시선은 약 9도 높였습니다.

11/28 폰 조작 수정: 상자 위 세로 스와이프로 스크롤, 가로로 끌면 흔들기. 스크롤 추종을 빠르게 하고 그림자/반사 갱신을 분산했습니다. 자동 검사 10개 통과(건너뜀 0)·브라우저 확인을 마쳤으며 실제 플립6 체감 재확인은 남아 있습니다.

사용한 외부 자료: three.js (MIT), Rapier (Apache-2.0), ambientCG WoodFloor051 · Concrete030 (CC0), Noto Serif KR · Noto Sans KR · Nanum Pen Script (SIL OFL).

11/28 제출 전 검수: HTML 동작은 유지하고 공유 미리보기 `og-finale.jpg`를 최신 화면으로 갱신했습니다.

11/28 폰 선명도 수정: 낮아진 해상도가 정상60Hz에서도 회복되도록 고치고 후처리 화면의 테두리 보정을 추가했습니다. 모바일은 기기 밀도 안에서 DPR1.25~1.75로 조절합니다(효과를 줄인 단계의 상한1.5). 관련19개 검사 통과(건너뜀0)·브라우저 전후 화면 확인을 마쳤으며 실제 플립6의 화질·성능·발열은 재확인이 필요합니다.
